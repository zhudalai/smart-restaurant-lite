# Prompt 迭代记录 — AI 日报生成

## Prompt 版本 1（初版）

```
以下のデータから営業日報を書いてください。
日付: {date}
売上: {revenue}円
注文数: {order_count}件
```

**问题**：输出太长（超过 500 字），不够简洁，没有日语敬体。

---

## Prompt 版本 2（加约束）

```
以下のデータから営業日報を100字以内で書いてください。
日付: {date}
売上: {revenue}円
注文数: {order_count}件
トップ商品: {top_items}
```

**问题**：长度控制了，但语气太机械，没有经营洞察。

---

## Prompt 版本 3（最终版）

**System Prompt**：
```
あなたは飲食店の経営コンサルタントです。データを元に簡潔な日本語で営業日報を書いてください。100字以内。
```

**User Prompt**：
```
日付: {date}
注文数: {order_count}
売上: ¥{total_revenue}
平均単価: ¥{avg_order_value}
トップ商品: {items}

このデータから今日の営業所感を100字以内で書いてください。
```

**效果**：✅ 输出简洁、专业、有经营洞察，日语自然。

**示例输出**：
> 2026年5月25日の営業報告です。注文数は4件、売上は5,580円、平均単価は1,395円で好調でした。トップ商品は抹茶アイス、オレンジジュース、コーラ、まぐろ、烏龍茶でした。ランチタイムの客足も安定しており、夕方以降の需要も徐々に回復傾向にあります。引き続き、顧客ニーズに合わせたメニュー開発と販促に力を入れていきます。

---

## 关键 Prompt 工程经验

1. **System Prompt 设定角色**：让 LLM 扮演「经营顾问」而非「数据处理器」，输出质量显著提升
2. **明确字数约束**：「100字以内」比「简洁」更有效
3. **结构化数据输入**：用换行分隔不同字段，比逗号分隔更清晰
4. **Fallback 机制**：API 不可用时，用模板生成基础日报，保证系统可用性
